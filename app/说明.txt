爱弥斯 v2 桌面宠
================

双击「启动爱弥斯.vbs」即可，不需要安装任何东西
（用的是 Windows 自带的 PowerShell + WPF）。


她会自己动
----------

你不用管她，她会在屏幕底部自己走来走去：走到某处停下、发呆一会儿、
偶尔挥挥手、跳一下、或者做一次「检视」动作，然后再决定下一步去哪。
拖动她之后，她会从落点继续自由活动。


怎么玩
------

  什么都不做        她自己散步、发呆、偶尔做小动作
  鼠标移到别处      她会用 16 个方向里的对应方向看向你的鼠标
  拖动她            跟着走，并播放朝左/朝右的跑动动画
  单击她            挥手打招呼
  右键点她          菜单，见下


右键菜单
--------

  挥手 / 跳一下 / 失败一下 / 工作一下   手动触发动作
  和她说句话…      弹出输入框，把话发给 AI 模型，回复显示在头顶气泡里
  测试 AI 连接     发一句测试请求，确认 API 通不通
  AI 状态          显示当前配置状态
  查看用量（tokens） 显示本次会话的调用次数与 token 消耗
  查询余额         向服务商查询账户余额（见下方说明）
  打开 AI 配置（记事本）
  重新载入 AI 配置   改完配置不用重启
  偷吃快捷方式      勾选 = 她偶尔会"吃"掉一个桌面快捷方式（默认关）
  真吃模式（会移动桌面文件）  勾选 = 真的移动文件（默认关，见下方安全说明）
  看看她肚子里有什么 / 吐出肚子里的东西
  自由活动        勾选 = 自己走动（默认开）
  声音            勾选 = 有音效（默认开）
  说话（机器音）  勾选 = 用 Windows 语音念出来（默认关）
  看向鼠标        开关鼠标跟随
  回到右下角      把她放回初始位置
  退出            关闭（退出时会把肚子里的东西还回去）


偷吃快捷方式（会动到桌面文件，请先读完）
------------------------------------------

这个功能默认是**安全模式**：只做咀嚼动画和气泡，说一句「嗯…「XX」看起来很好吃~」，
**完全不碰你的文件**。

想让她真的把图标吃掉，需要你在菜单里**显式打开「真吃模式」**。真吃模式的行为边界：

  * 只动**桌面最顶层目录**里的 **.lnk** 文件
  * **不碰**文件夹、不递归子目录、不碰 .url / .exe / 任何其他类型
  * **只移动，绝不删除**；移动前记录原始完整路径
  * 目标重名时改名，**绝不覆盖**
  * **退出程序时自动全部还原**
  * **下次启动时也会先还原**——就算你强制杀进程，东西也不会丢
  * 菜单里随时可以「吐出肚子里的东西」
  * 暂存目录是 app\belly\，已被 .gitignore 挡住，不会进仓库

万一真出了意外，你的快捷方式就在 `app\belly\` 里，手动拖回桌面即可。


余额与用量
----------

**用量（tokens）**：每次收到回复都会读取接口返回的 usage 字段并累加，
右键「查看用量（tokens）」可以看到本次会话的调用次数、输入/输出 token 数。
这个对任何 OpenAI 兼容接口都有效。

**余额**：不同服务商的余额接口不一样，程序按 base_url 自动判断：

  DeepSeek        /user/balance
  硅基流动        /user/info
  Moonshot        /users/me/balance
  OpenAI 官方     /dashboard/billing/credit_grants
  其他中转        依次尝试上面几个，都不行就如实告诉你

**如实说明**：OpenAI 官方**没有**给 API key 用的公开余额接口
（那个 billing 端点通常只认网页会话，不认 API key），所以用官方 key 时
「查询余额」大概率会失败。这不是程序的问题，是官方没提供。


接 AI 模型（在程序里直接填）
----------------------------

右键她 →「**API 设置…（自定义提供方）**」，弹出面板里填这些：

  **选择或新建提供方**  下拉里选已有的，或直接输入新的 Provider ID
  **Provider ID**       以小写字母开头，只能含小写字母、数字、连字符
                        例如 acme-gateway。它用来唯一标识这个提供方，
                        并用于派生凭据名（配置里就存在这个键下面）
  **显示名称**          给自己看的名字，随意填
  **API 地址**          例如 https://gateway.example/v1
  **API 协议**          openai-completions（目前实际生效的就是它）
  **API 密钥**          输入框默认打码，可勾「显示密钥」查看
  **代理（可选）**      访问国外接口连不上时填，例如 http://127.0.0.1:7892
                        留空表示跟随系统代理。国内接口（DeepSeek 等）不用填
  **模型目录**          点「获取可用模型」会去拉 {地址}/models 的列表，
                        从下拉里挑一个；也可以直接手输模型名
  **保存并启用**        写入配置并立即生效，不用重启

**连不上怎么办**：先用命令行确认是网络问题还是配置问题——

  ... -File AemeathPet.ps1 -ListModels

它会直接告诉你失败原因。常见的三种：

  HTTP 401          密钥无效或没填
  HTTP 404          地址不对，要填到 /v1 这一层
  连接超时/连不上    该服务商需要代理，在「代理」栏填上你的本地代理地址

**实测参考**（本机环境）：直连 api.openai.com 是不通的，
必须走代理；而 DeepSeek 等国内接口直连即可。

重复上面的步骤可以添加多个提供方，随时在下拉里切换。

配置存在本机 `ai-config.json`（版本 2，多提供方结构）：

  {
    "version": 2,
    "enabled": true,
    "active_provider": "acme-gateway",
    "providers": {
      "acme-gateway": {
        "display_name": "我的中转",
        "base_url": "https://gateway.example/v1",
        "protocol": "openai-completions",
        "api_key": "……",
        "model": "gpt-4o-mini",
        "models": ["……"]
      }
    }
  }

老版本那种扁平配置（enabled/base_url/api_key/model）会在启动时**自动迁移**
成上面的结构，Provider ID 从主机名派生。

任何 **OpenAI 兼容**的接口都能接：

  官方 OpenAI      https://api.openai.com/v1       模型如 gpt-4o-mini
  DeepSeek         https://api.deepseek.com/v1     模型 deepseek-chat
  硅基流动         https://api.siliconflow.cn/v1   模型 Qwen/Qwen2.5-7B-Instruct
  本地 Ollama      http://localhost:11434/v1       模型 qwen2.5（密钥随便填）
  本地 LM Studio   http://localhost:1234/v1        密钥随便填

不开界面也能验证：

  ... -File AemeathPet.ps1 -TestAi                  发一句话，看能不能通
  ... -File AemeathPet.ps1 -ListModels              拉当前提供方的模型列表
  ... -File AemeathPet.ps1 -ValidateProviderId abc  验证 ID 规则

密钥只存在本机这个 json 里，程序不会打印、不会上传到任何地方。
它只会在你主动点「和她说句话」「测试 AI 连接」「查询余额」时才发请求。

**已知限制**：code0.ai 那个中转的 /v1/models 只列出 6 个图像模型、
没有对话模型，所以那个 key 大概率聊不了天。要用对话功能请换一个支持
chat/completions 的接口。


关于声音
--------

音效是**程序合成的提示音**（叮咚、啵、下行音等 7 个），不是爱弥斯的真实语音。
我没有游戏语音资源，也不应该去抓有版权的语音。

  sounds\hello.wav    挥手 / 打招呼        sounds\review.wav  检视
  sounds\jump.wav     跳跃                 sounds\step.wav    起步走动
  sounds\fail.wav     失败                 sounds\chirp.wav   发呆时偶尔的轻鸣
  sounds\work.wav     工作中


关于画面清晰度
--------------

交付用的 Codex 图集受格式限制，每格只有 192x208，直接放大显示会发虚。
所以程序用的是**从原始条带重建的高清图集** `spritesheet-hires.png`
（3072x4576，每格 384x416，与显示尺寸 1:1）。

各行原生分辨率不一样，重建时如实统计过：

  idle / waving / waiting / running / review / 转头行   原生 1.5 ~ 1.85 倍   高清来源
  running-right / running-left / jumping / failed       原生 1.0 ~ 1.5 倍    靠插值

想重新生成高清图集（改完原始条带后）：

  python build_hires_spritesheet.py


文件说明
--------

  启动爱弥斯.vbs     推荐用这个双击启动（不会闪黑窗口）
  启动爱弥斯.bat     备用启动方式（会短暂闪一个黑窗口）
  AemeathPet.ps1     主程序
  ai-config.json     AI 接口配置（自己填密钥）
  spritesheet-hires.png  高清图集（程序实际使用）
  spritesheet.png    交付图集 1536x2288（备用）
  sounds\            7 个程序合成的音效
  previews\          9 个动作的动图预览
  aemeath-pet.log    运行日志（出问题时看这个）


图集里有什么
------------

  行 0   idle          6 帧   待机          行 6   waiting       6 帧   等待
  行 1   running-right 8 帧   向右走        行 7   running       6 帧   工作中
  行 2   running-left  8 帧   向左走        行 8   review        6 帧   检视
  行 3   waving        4 帧   挥手          行 9   转头 000-157.5   8 帧
  行 4   jumping       5 帧   跳跃          行 10  转头 180-337.5   8 帧
  行 5   failed        8 帧   失败


想调整
------

  大小          编辑「启动爱弥斯.vbs」，命令末尾加 -Scale 3（默认 2 倍）
  走路速度      加 -WalkSpeed 10（默认 6，数字越大越快）
  不要自由活动  加 -NoRoam
  完全不用 AI   加 -NoAi
  静音启动      加 -Mute
  帧率          加 -IdleFrameMs 150 -LookFrameMs 90 -RunFrameMs 80

  自检（都不弹窗）：
    ... -File AemeathPet.ps1 -SelfTest        渲染链路 + 走动 + 音效加载
    ... -File AemeathPet.ps1 -PerfTest 900    每帧耗时统计
    ... -File AemeathPet.ps1 -TestAi          AI 接口连通性


已知的小毛病
------------

  * 转头幅度偏含蓄：16 个方向都能看出来，但不算强烈。
  * running（工作中）动作偏安静，主要靠神态和手部小动作表达。
  * 走动只在水平方向，不会爬窗口或走斜坡。
  * 用高清图集后内存约 250MB（图集解码后约 56MB，其余是 WPF 与 PowerShell 本身）。
    介意的话可以把 spritesheet-hires.png 改名，程序会自动退回 192x208 的交付图集。
